# Security Policy

## Reporting a Vulnerability

To report a security issue, open a private advisory:

**https://github.com/KatrielMoses/voidaccess/security/advisories/new**

Please include:

- A description of the issue
- The affected version or commit
- Steps to reproduce, or a proof of concept
- The impact as you see it

Please don't open a public issue or pull request for a vulnerability. Every advisory is reviewed, and you'll get a response in the advisory thread.
